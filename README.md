🎮 Catálogo de Jogos

👩‍💻 Aluna: Alana Escobar de Brito

📖 Descrição
Aplicação desenvolvida em Angular para apresentar informações sobre jogos de forma interativa.
O projeto tem como objetivo praticar conceitos de desenvolvimento front-end e explorar recursos do framework Angular.

✨ Funcionalidades

📂 Listagem de jogos: exibição organizada dos títulos disponíveis.
🔍 Detalhes do jogo: visualização de informações específicas de cada jogo.
✅ Disponibilidade: identificação de quais jogos estão acessíveis.
🔑 Login fictício: simulação de autenticação de usuário.

🛠️ Tecnologias utilizadas
- Angular
- TypeScript
- HTML
- CSS

## Como executar
1. Baixe ou clone o repositório.
2. Execute `npm install`.
3. Execute `ng serve`.
4. Acesse `http://localhost:4200`.
